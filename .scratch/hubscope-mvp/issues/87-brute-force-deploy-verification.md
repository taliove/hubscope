## 实测记录(测试线,2026-07-28,版本 dev-20260728-094924)

1. **部署**:`deploy.sh dev` 门禁绿(后端+前端测试)→ 备份 → 构建 → 换容器 → healthz 200。
2. **渐进延迟**(ghostuser,10 分钟窗口):#1-5 = 2-7ms(阈值内无延迟);#6/7/8 = **2.008s / 4.007s / 8.007s**(退避精确命中);delaytest 正确密码 = **200 / 63ms**(立即放行);成功后 delaytest 再失败 = 58ms(计数清零)。**全部符合 spec 0011 决策 3**。

4. **爆破告警(静默跳过路径)**:测试线 settings 无 webhook/alert_enabled;ghostuser 8 次 + delaytest 1 次 + ghostuser2 2 次 = 11 次失败越阈(≥10),容器日志 grep error/warn 为空——冷却在越阈当下消费、无 webhook 静默跳过的语义成立,未刷屏。
5. **已知残留实证**:ghostuser(不存在)失败 2ms vs delaytest(存在)密码错 58ms——bcrypt 时序旁路肉眼可见,与 ticket 85 备注登记一致;阈值之上被 2s+ 延迟掩盖。
