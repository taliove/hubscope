# 05 — 模型自动发现

**What to build:** 模型清单从纯手工变成自动:系统每小时拉取各 Hub 的 `/v1/models`,新出现的模型自动登记并试通双协议——通的协议建启用 Endpoint,不通的建停用 Endpoint;从列表消失的模型标记为下线(停止探测,历史数据保留);识别非对话模型(如 gpt-image-2)并打上 non_chat 能力标签。管理员仍可在管理页手工增模型、逐 Endpoint 启停。

**Blocked by:** 02 — 定时探测调度

**Status:** ready-for-agent

- [ ] 同步后新模型自动出现在列表并开始按节奏探测(通的协议)
- [ ] 列表中消失的模型标记下线、不再产生新 Probe,历史曲线仍可查
- [ ] 自动发现的协议探测结果可见(哪条协议通、哪条不通及原因)
- [ ] 非对话模型被标记 non_chat,不出现在后续评估候选中
- [ ] 黑盒测试:stub Hub 改变 `/v1/models` 返回,推进时钟,经 API 断言新增/下线/协议启停正确
