# 12 — 端点/模型删除

**What to build:** 补齐删除能力:DELETE /api/endpoints/{id} 删除任意单个端点(含 discovered 的;同步只在模型首次注册时建端点,不会复活已删端点),级联删除其 probes 与 alert_events 历史;DELETE /api/models/{id} 仅允许删除 manual 模型,级联删除其全部端点及历史;discovered 模型删除返回 409(提示用禁用代替,防止下次同步复活)。前端管理页:端点行加删除按钮(二次确认),manual 模型行加删除按钮(二次确认,说明级联影响)。

**Blocked by:** 无

**Status:** todo

- [ ] 任意端点可单独删除,其探测历史与告警事件一并清除
- [ ] manual 模型可整体删除,级联端点与历史;discovered 模型删除返回 409
- [ ] 删除后调度器不再对该端点派发探测,进行中的轮次安全收尾
- [ ] 前端删除均有二次确认,模型删除提示级联范围
- [ ] 黑盒测试:经 API 删除端点/模型后,列表/详情/历史查询断言数据已清、外键无悬挂
