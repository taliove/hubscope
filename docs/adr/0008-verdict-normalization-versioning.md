# 判分归一化管道 + 口径版本化

exact 判分历史上只做 `TrimSpace`,模型作答 `"e"`(带引号)、全角 `ｅ`、多余空白均被误判 0 分——判分器缺陷直接污染题库区分度。但改判分规则等于换尺子:ADR 0007 的"跨时间可比"前提是所有历史 Run 用同一把尺子,直接硬改会让新旧 Run 不可比。因此:判分器引入归一化管道(trim、去成对引号、Unicode NFKC 全半角归一、折叠内部空白;**大小写保持敏感**——指令遵循类题目严格性是有意为之),管道整体版本化为 **Verdict Profile(判分口径)**,评估结果记录所用口径版本;报告层遇口径版本断裂时复用 ADR 0007 既有断点机制(趋势照画、标注断点、不比涨跌、分数大跌告警跳过)。曾考虑 Case 级归一化配置(不动旧题尺子),但它不解决存量题的误判问题,被否。代价:结果表多一个口径版本字段,报告层多一种断点类型;换来判分器可以持续修正而不破坏可比性承诺。
