# 报告分享用免登录 token 链接

"想分享"的诉求意味着报告要给未登录的人看。选择为每个 Campaign 报告生成带随机 token 的只读链接(/report/{token}),无需登录、可撤销;这在 ticket 16 建立的读权限分级上刻意开了一个"凭链接即读"的口子。备选:导出图片/PDF 分发(静态、无法钻取 Case 详情;仍要做,但排在链接之后)、只分享给已登录同事(不满足对外分享诉求)。控制面:token 高熵随机、仅只读、仅暴露单个 Campaign 报告、撤销即失效、创建与撤销走审计。

「仅暴露单个 Campaign 报告」含报告生命周期全程(ticket 54 细化):未完成批次的分享面只出进度元数据(模型 × 能力点运行状态 + 判分覆盖计数),分数、名次、涨跌等评估性数据在批次 settle 前不出公开面;settle 后分享面与登录视图渲染同一完整榜单。
