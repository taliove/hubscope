# UI v2.0 完全重构:推翻品牌色承诺、四态词表与闪烁独占三处承重语义

**Status:** accepted(2026-07-31,spec 0018,GH #109 / GH #110)

## 决策

v2.0 设计简报(Apple 风)为 UI 唯一事实源,完全重构、不向现状兼容(spec 0018 决策栈 #1–#11)。本 ADR 记录对三处既有承重语义/承诺的推翻:

1. **品牌承诺(PRODUCT.md):** 品牌色由 teal 电波青(`--hs-teal-*` 刻度,锚 #0b7a72)改为 Apple 蓝 `#007AFF`;BrandMark 渐变随品牌色重建(瞄准镜字形不动),与 ProxyHub 的家族同源关系解除登记。
2. **状态词表(ui-guidelines §7 / §3):** endpoint 四态中文词表「正常 / 降级 / 宕机 / 告警」改为三态「稳定 / 性能下降 / 服务异常」,failing 档在**显示层**并入服务异常(红);状态呈现统一为「小圆点 + 状态词」双编码,禁大面积红色标签。
3. **动效语义(ui-guidelines §3):** 「闪烁 = failing 告警专属、全站唯一动画」整条退役——禁闪烁,动效改走 v2.0 §15 体系(数字补间 / 状态点呼吸 / 图表入场绘制 / 页面 Fade+Slight Move / hover 上浮 / 局部刷新),reduced-motion 全局门控平移保留。

**不动的部分(边界):** 后端状态机与告警管线(W5)零改动——failing 档保留在域模型、Lark 告警与告警历史;三态是显示层映射,不是域模型变更。评估域(W7)、凭证边界(W6)、存储与 schema(W2)、唯一测试接缝(W1)、调度器时钟(W4)、单二进制交付(W8)全部不动。

## 承重墙四问

1. **为什么必须改:** 用户两轮明确裁决完全重构(原话:「所有的设计全部按照我发的来,不要想着跟现有兼容,我们是完全重构」),v2.0 简报为唯一事实源。旧世界的三根支柱与新方向逐项冲突:teal 品牌与 `#007AFF` 锚点互斥;四态词表与「三态中文主显」互斥;「闪烁独占」与「禁闪烁 + §15 动效体系」互斥。定向演进(保留承重语义、吸收 Apple 语法)已被用户否决,不存在兼容并存的第三条路。
2. **影响哪些调用方:** 显示层全部——StatusBadge / HealthBanner / EndpointCard / UptimeStrip / EndpointQuickViewDialog / StatusCard / EvalCard / 图表色板镜像,随批次退役或重建;规范层——PRODUCT.md 品牌承诺段、DESIGN.md、ui-guidelines.md、四份 surface briefs 全部重写(批末 T13 统一,不留混合态规范)。**后端零改动**:failing 档保留于域模型、Lark 告警、告警历史与 `utils/alertKind.ts` 事件词表(审计域,非状态词表);告警相关既有 W1 测试全量保持绿,作为「W5 后端不动」的回归证据。
3. **有无替代方案:** ① 定向演进(保留 teal / 四态 / 闪烁语义,仅吸收 Apple 语法)——用户否决;② 换深色蓝保 WCAG AA(`#007AFF` 白底实测 4.02:1,不过 4.5)——用户否决,按简报原文执行;③ 三态英文主显(Stable / Degraded / Incident)——用户否决,中文主显、英文为译名档案。
4. **回归测试什么:** 四→三状态映射纯函数 vitest 全组合(四入三出);健康指数与日环比聚合走 W1 接缝黑盒测试(httptest + stub Hub + 假时钟 + 真 SQLite,不新增接缝);告警管线既有生命周期测试(Lark lifecycle / 聚合窗口 / 分组告警 / 静默时段)全量保持绿;物料快照与导出测试按新世界重建;每批完成后全量 `make test`。

## 已登记的代价(用户已知并接受)

- `#007AFF` 白底 4.02:1 不过 WCAG AA 4.5(品牌色文字用法从简、关键文本用墨色缓解;a11y 基线本就未建立,登记为开放事实延续)。
- 告警紧急档在状态板显示层消失(域模型与 Lark 告警保留);状态板「服务异常」不再区分「已宕机」与「告警中」。
- 分批期间新旧视觉世界并存(骨架先行的固有混合态,spec 0018 决策 9 登记)。
- 暗色主题缺席期:令牌三层保留双值能力(暗色键位预留、值暂沿亮值),后续独立 spec 定稿,不返工(决策 10)。
- 功能色图形档本体按简报原文执行:`#34C759` / `#FF9500` 白底实测 2.2:1 不过图形 3:1 门槛,文字场景由分工阶(`--hs-success-text` / `--hs-warning-text` / `--hs-danger-text`,实测均过 AA)承担,实测值逐条注释在 tokens.css。
