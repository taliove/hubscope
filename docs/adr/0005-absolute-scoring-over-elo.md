# 排行榜用绝对分制而非 Elo

报告排行榜的外观对标 DesignArena(Elo 柱状榜),但评分采用绝对分:每 Suite 为 Case 均分 × 100,总分为各 Suite 加权平均(默认等权)。Elo 是相对分,靠两两对战攒出,本周整体水平下滑时第一名分数可以不变——无法发现供应商降级/偷换模型,与"看走势、防作假"的核心诉求直接冲突;且我们的判分是固定题库确定性打分,不存在对战关系。不做 Win Rate(无对战即无胜率)。代价:总分随题库版本变化而不可跨版本比较,由 Suite 版本化与趋势断点标注兜底。

> 刻度修正(2026-07-22):本 ADR 的内核(非 Elo、非排名、确定性打分)保留;"原始均分直出 0–100"的刻度由 ADR 0009 修正为 nadir 归一化定标。
