# 题库 v3:按能力点重构 + 定期轮换

旧题库(4 Suite × 12 题,toy 题为主)有三个结构性缺陷:题目太人工易被"应试"、单 Suite 12 题导致单题权重 8.3%(一道误判抖动 8 分,统计上不稳)、"中文"这类语言维度与能力维度交叉。题库 v3 按**能力点(Capability)**重构:Suite = 能力点(指令遵循/推理/代码/语言理解与生成等),每能力点 30–50 题、每题声明所测能力点;新增题型为结构化抽取、多步推理、代码理解、长文本摘要——全部落在现有 rule/judge 双判分器上,**明确不做多轮对话与工具调用**(需改评估执行模型,工程量另计)。不移植公开基准(MMLU/HumanEval 等):公开题会被训练数据污染、供应商可背诵,自产题库是 ADR 0007 防作假语义的壁垒。生产走 LLM 批量生成 + 人工审题 + 真实场景招牌题精写;**季度轮换约 30% 题目**(退役+铸新),复用 suite_version 断点机制,天然防"题库被背下来"。judge 题占比 ≤40%(成本与方差控制),judge 题 sampleCount=3、rule 题保持 1。代价:题库运营成为持续性工作(审题、轮换);换来分数的统计稳定性与长期防污染。
