# Nadir 归一化定标(修正 ADR 0005 的刻度)

ADR 0005 的内核保留:非 Elo、非排名分、分数是模型自身表现的确定函数、不存在对战关系。修正的是刻度:原始均分直出 0–100 时模型分数全挤在高位、区分度差,且"全错=0 分"的刻度把"等于瞎猜"和"完全无效"混为一谈。改为 **Nadir 归一化**(Open LLM Leaderboard 式):每个能力点随 Suite 版本锁定一个 nadir 常数(下限基线,审题时人工标定:选择题类按随机猜测率,开放题按空答/乱答基线),分数 =(原始分 − nadir)/(1 − nadir)× 100,clamp 到 [0,100];nadir 随 suite_version 一起版本化,跨版本照旧走 ADR 0007 断点不比。曾考虑 Geekbench 式参考锚点(某模型=锚定分)与百分位分,均被否:锚模型自身漂移会带崩全榜单刻度,百分位分随对手阵容变化,二者都摧毁"看走势、防作假"的纵向可比性——跑分感必须由固定常数刻度提供,不能由相对量提供。代价:每能力点每次铸库要多标定一个常数;换来分数分布拉开、刻度语义可解释("0 分 = 与乱答无异")。
